PUBLICACIÓN EN GITHUB PAGES

1. Descomprima este paquete.
2. Suba TODO el contenido al repositorio de GitHub.
3. Verifique que index.html quede en la raíz del repositorio.
4. En GitHub: Settings -> Pages.
5. Source: Deploy from a branch.
6. Branch: main / (root).
7. Espere unos minutos y abra la URL publicada.

Estructura:
- index.html: portada del sitio
- anexos/: páginas HTML con visor PDF y botón Regresar
- docs/: PDFs para visualización y DOCX para descarga
- styles.css: estilos del sitio
- .nojekyll: evita procesamiento Jekyll
